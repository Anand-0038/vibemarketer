## Verified official setup references

- [ZCP Quickstart](https://docs.zerops.io/zcp/quickstart) — requires a Zerops account with project-creation permission and an authenticated coding-agent subscription; a recipe with an AI Agent environment provisions the remote `zcp@1` workspace.
- [Remote or local ZCP setup](https://docs.zerops.io/zcp/setup/choose-workspace) — remote setup keeps the agent workspace and private-network access inside Zerops; local setup runs beside the local source tree and stores its project token in `.mcp.json`.
- [Zerops zCLI](https://docs.zerops.io/references/cli) — optional terminal path; supports Linux, macOS, and Windows and uses a Zerops personal access token.
- [Zerops logging](https://docs.zerops.io/references/logging) — keep available for deployment/runtime troubleshooting once a project exists.
